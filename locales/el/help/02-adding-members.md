## Η φόρμα

Ανοίξτε **Μέλη** από την πλαϊνή μπάρα, μετά κλικ στο **Προσθήκη μέλους**
πάνω δεξιά. Η φόρμα έχει τρεις ενότητες:

### 1. Ποιοι είναι

- **Πλήρες όνομα** — υποχρεωτικό. Χρησιμοποιήστε το όνομα που αναγνωρίζουν.
- **Αριθμός μέλους** — προαιρετικό. Αν το αφήσετε κενό, θα δημιουργήσουμε
  έναν στη μορφή `M-2026-0001`. Αν η βιβλιοθήκη σας χρησιμοποιεί ήδη
  αρίθμηση (αυτοκόλλητο, κάρτα), πληκτρολογήστε το εδώ για να τη
  διατηρήσουμε.
- **Ημερομηνία γέννησης** — προαιρετική. Χρήσιμη αν έχετε κανόνες
  δανεισμού με βάση την ηλικία.

### 2. Πώς να επικοινωνείτε μαζί τους

Email, τηλέφωνο, διεύθυνση. Όλα προαιρετικά — μια βιβλιοθήκη με λιτές
εγγραφές είναι μια χαρά. Αν συμπληρώσετε email, θα το χρησιμοποιήσουμε
για όποια πρότυπα ειδοποιήσεων ρυθμίσετε αργότερα.

### 3. Στοιχεία που σας αφορούν

Αν η βιβλιοθήκη σας έχει προσαρμοσμένα πεδία για μέλη (από
**Ρυθμίσεις → Μοντέλο δεδομένων**), εμφανίζονται στο κάτω μέρος της
φόρμας. Οι ετικέτες που ορίσατε στον επεξεργαστή είναι αυτές που
βλέπετε εδώ.

## Μετά την υποβολή

Θα προσγειωθείτε στη **σελίδα λεπτομερειών** του μέλους — πλήρης
εγγραφή αριστερά, φωτογραφία και στατιστικά δεξιά. Από εδώ μπορείτε:

- Να **επεξεργαστείτε** ό,τι πληκτρολογήσατε.
- Να **αναστείλετε** το μέλος προσωρινά (δεν μπορεί να δανειστεί μέχρι
  να επανενεργοποιηθεί).
- Να το **αρχειοθετήσετε** όταν φύγει (το Libriant κρατά το ιστορικό
  δανεισμών· η αρχειοθέτηση είναι αναστρέψιμη).
- Να **ανεβάσετε φωτογραφία** για την κάρτα μέλους.

## Μαζική εισαγωγή

Έρχεται στην επόμενη έκδοση. Για τώρα, το API δέχεται JSON αν θέλετε να
γράψετε ένα one-off script από spreadsheet — επικοινωνήστε μαζί μας και
θα σας καθοδηγήσουμε.
