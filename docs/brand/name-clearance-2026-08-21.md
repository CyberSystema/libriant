# Name clearance — preliminary search, 2026-08-21

> **This is not a trademark clearance search.** It is a preliminary availability
> check run from public web sources. The authoritative registers (EUIPO eSearch,
> TMview, WIPO Global Brand Database) are JavaScript applications behind CAPTCHAs
> and **could not be queried** — see "What was not checked". A real clearance
> opinion covers _confusingly similar_ marks in the relevant classes, not just
> identical strings, and is work for a trademark attorney.

## Libriant

Searched: general web, trademark aggregators (Trademark Elite, Trademarkia,
Justia), library-software vendor listings.

Found **no** company, product, software, or trademark using the name. The only
occurrences are unrelated to commerce:

- a very rare given name / surname (mondonomo, forebears.io)
- a handful of personal social handles (Instagram, Twitch)
- a small music artist releasing on Apple Music / Amazon Music (2024)

None of these are in Class 9 (software) or Class 42 (SaaS), and none appear to be
trading marks. **Nothing found that would block use or registration.**

Distinctiveness is the good news here: "Libriant" is a coined word. It suggests
_libri_ (books) without describing library software, which is exactly the
profile that registers well and is enforceable. Compare it to the descriptive
names it competes against — Ex Libris, LibLime, Libramatic, Librarika — all of
which are weaker for exactly that reason.

**Adjacent marks that a real clearance search must weigh** (found, not assessed):

- **Ex Libris** — the dominant library-software vendor, owned by Clarivate. Will
  hold EU marks in Classes 9/42. Shares the _libri_ root.
- **LIBRIS** — the Swedish national union catalogue.
- **Libri** — German book wholesaler, holds EU marks.
- **Libby** — OverDrive's library app; large and heavily protected.

My own read is that "Libriant" is unlikely to be confused with any of these —
different length, different ending, different overall impression — but _that
judgement is exactly what you pay an attorney for_, and the overlap is in the
same classes, which is what makes it worth asking.

## CyberSystema

No exact match found. But the surrounding namespace is dense with near-identical
IT companies:

| Name                           | Where                               |
| ------------------------------ | ----------------------------------- |
| CyberSystems                   | Moldova — IT / business software    |
| Cybersystems GmbH              | Germany                             |
| CyberSystem (`cybersystem.io`) | cybersecurity                       |
| CyberSystem (`cybersystem.ca`) | Canada — cybersecurity / networking |
| Cyber System                   | US — healthcare IT                  |
| Cybernet Systems Corporation   | US                                  |
| CyberStep                      | Japan                               |

This matters practically. "Cyber" + "system" are near-descriptive terms in IT, so
the mark is **inherently weak**: harder to register, easier to oppose, harder to
enforce, and it will fight for search visibility against every name above. That
is a reason to keep CyberSystema as an umbrella _trading name_ rather than
invest in defending it as a trademark.

## What was NOT checked

Do not treat this document as covering any of it:

1. **EUIPO / TMview / WIPO registers** — all JavaScript + CAPTCHA, unreachable
   from an automated fetch. **These are the ones that actually matter.**
2. **The Greek national register (OBI)** — same limitation.
3. **Confusingly similar marks** — only identical-string searching was possible.
   Phonetic and conceptual similarity in Classes 9/42 is the real risk surface.
4. **ΓΕΜΗ company-name availability** — a Greek company name must be
   distinguishable from existing ones; that is a separate register from trademarks.
5. **Non-EU jurisdictions.**

## Do these yourself before committing further

1. **TMview** — <https://www.tmview.org/> — the official cross-office search;
   aggregates EUIPO, OBI (Greece), WIPO and dozens more in one query. Run
   `Libriant` in "Is", "Begins with" and "Contains" modes, filtered to Classes 9
   and 42. Free.
2. **OBI availability check** —
   <https://www.obi.gr/en/trademarks/trade-mark-registration-procedure/trade-marks-availability-check/>
   for Greek national marks.
3. **EUIPO** — <https://www.euipo.europa.eu/en/trade-marks> to file, once clear.
4. **ΓΕΜΗ** — company-name availability, at incorporation.

If TMview comes back clean in Classes 9 and 42, an **EU trade mark (EUTM)** for
_Libriant_ is the proportionate move: one filing covers all 27 member states, and
it is the asset worth owning.

## Effect on the codebase

None. Nothing is registered, so the site and the email make **no trademark claim
at all** — no ™, no ®, no ownership line. Naming a status the reader has no reason
to care about only adds noise.

If a mark is ever registered, add ® at that point (and not before — using ® on an
unregistered mark is an offence in several EU jurisdictions).
